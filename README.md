# WaveLink – Telecom Website

**Stronger Signals. Better Connections.**

WaveLink is a responsive telecom website developed as a Full Stack Web Development group project using HTML5, CSS3, and JavaScript ES6.

The project is inspired by modern telecom websites and features an original design with interactive broadband and mobile plan services.

## Features

- Responsive homepage with navigation and service cards
- Broadband plans with search, filters, sorting, and comparison
- Mobile and SIM offers with search and sorting
- Interactive package calculator
- Demo postcode availability checker
- Contact form validation
- Frequently Asked Questions (FAQ) section
- Responsive design for desktop, tablet, and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript ES6


## Pages

1. Home – `index.html`
2. Broadband – `broadband.html`
3. Mobile & Offers – `mobile.html`
4. Contact & Support – `contact.html`


## Team Project

Developed collaboratively as part of a Full Stack Web Development course.

## Disclaimer

WaveLink is an educational front-end demonstration. All prices, offers, and availability results are fictional. It is not affiliated with BT or any telecom provider.
