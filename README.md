# 🌐 WaveLink – Responsive Telecom Website

**Stay Connected. Stay Ahead.**

WaveLink is a responsive, interactive telecom website developed as a **Full Stack Web Development (FSWD) student group project – Team 6**.

The project is inspired by modern telecom service websites and provides a user-friendly platform to explore broadband connections, mobile and SIM plans, bundled services, and customer support.

Built using **HTML, CSS, JavaScript, and Tailwind CSS**, WaveLink demonstrates frontend development, DOM manipulation, form validation, responsive layouts, and interactive website functionality.

---

## 🚀 Features

### 🏠 Home Page
- Modern and responsive homepage
- Interactive navigation bar
- Broadband and mobile service highlights
- Promotional offers and service information
- Mobile-friendly navigation menu

### 🌐 Broadband Plans
- Explore different fibre broadband packages
- Compare broadband plans based on speed and price
- Search and filter available plans
- PIN code availability checker (demo)
- Responsive broadband plan cards

### 📱 Mobile & SIM Plans
- Explore prepaid, postpaid, and data-only plans
- Search mobile plans by name or features
- Filter plans by category and price
- Sort plans by price and data allowance
- Add plans to favourites
- Interactive plan recommendation tool
- View detailed plan information in a popup

### 📦 Wave Connect – Package Builder
- Build customised telecom packages
- Select broadband and mobile plans
- Add optional TV and OTT services
- Automatically calculate estimated package costs
- Demo postcode availability checker
- Embedded Google Maps

### 👤 Registration Page
- User registration form
- JavaScript form validation
- Username and password validation
- Error messages for invalid inputs
- Redirect to the registered-user homepage after successful validation

### 🎧 Help Center & Customer Support
- Frequently Asked Questions (FAQs)
- Category-based FAQ filtering
- Search functionality for questions
- Expandable questions and answers
- Contact form with validation
- Social media and customer support links
